# Den Bosch driving schools — interactive decision aid

A data-driven tool for choosing a driving school in the Den Bosch (’s-Hertogenbosch) region, built for an **English-speaking expat**. It enriches the official CBR pass-rate data with the things that actually matter — English instruction, transmission, school age, and the **content** of real reviews — and re-scores every school for trustworthiness.

**▶ Live tool:** https://rhnfzl.github.io/den-bosch-driving-schools/

> Open the link in a browser (works on phones too). It's a single self-contained HTML file — but it **must be loaded over a URL**, not opened as a local file, because file previews / iOS Quick Look disable JavaScript. A no-JS static fallback is included for previews.

## What it does

For each of the 121 CBR-listed car driving schools it adds:

- **English instruction** (yes / likely / no / unknown, with evidence) — the hard filter for an expat.
- **Transmission** (manual / automatic / both), **founding year / maturity**, contact + KvK.
- **Statistical reliability** — a Wilson 95% lower bound on the first-exam pass rate given the exam count (a 92%-from-30 and a 100%-from-1 are *not* the same bet).
- **Review intelligence** — instead of trusting star ratings (gameable, 5.0-inflated, ~0 correlation with pass rate), it reads the *actual review text*, judges **authenticity**, and scores **sentiment** with an LLM, then **gates the sentiment by how trustworthy the reviews look**.

**`decision_score`** = base (`0.85·quality + 0.15·maturity`) nudged by a trust-gated review-sentiment modifier. The raw star rating is deliberately **not** scored.

## Pipeline / how to regenerate

```
scripts/build_schools.py     # CBR CSV -> research/schools.json
# (review + enrichment gathering is done by external recursive-Tavily agents -> research/*.json)
scripts/sentiment.py         # OpenAI sentiment over review quotes -> research/sentiment/*.json
scripts/enrich.py            # merge + stats + scoring -> data/*.enriched + den_bosch_master.json
scripts/make_report.py       # -> report/den_bosch_rijschool_shortlist.md
scripts/make_html.py         # -> the interactive HTML (deployed here as index.html)
```

`sentiment.py` reads its key from `OPENAI_API_KEY` (or a `.env` path in `SENTIMENT_ENV_FILE`) — nothing is hardcoded.

## Layout

| Path | What |
|---|---|
| `index.html` | the deployed interactive tool (generated by `make_html.py`) |
| `scripts/` | the Python pipeline (stdlib only; `sentiment.py` calls the OpenAI API) |
| `data/` | source CBR CSV, enriched CSV + JSON, and `den_bosch_master.json` (full record) |
| `research/` | per-school raw research, review, and sentiment JSON (provenance) |
| `report/` | the static markdown shortlist + methodology |

## Data sources & privacy

- **Pass rates:** CBR Rijschoolzoeker — a rolling 12-month window (exact period depends on extraction date; CBR publishes no historical windows).
- **Everything else:** public web research (school sites, public aggregators, public reviews) + LLM sentiment.
- All figures are **estimates** — verify your final picks by phone. School names, phone numbers, websites, and KvK numbers are **public business information**. No personal user data and no API keys are stored in this repo.
